# 🎣 絵文字フィッシング

海・ホーム・ショップの3エリアを行き来しながら絵文字の魚を集める放置系ブラウザゲーム。

## 遊び方
- 🌊 **海**: 竿を投げて絵文字の魚を釣る
- 🏠 **ホーム**: 釣った魚を拠点マスに設置してコインを自動収集(毎秒)
- 🛒 **ショップ**: コインで釣り竿・幸運のお守り・拠点拡張を購入
- 📖 **図鑑**: 釣った魚の種類と、低確率で出現する✨金・🌈虹の変異個体を記録

セーブデータはブラウザの localStorage に自動保存されます。
